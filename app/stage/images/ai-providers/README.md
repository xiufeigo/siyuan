# AI provider logos

The image files in this directory are bundled locally so the AI settings UI does not hotlink third-party assets.

The `anthropic.svg` file comes from [Simple Icons 16.27.0](https://github.com/simple-icons/simple-icons/blob/16.27.0/icons/anthropic.svg), preserving its original path geometry and transparent 24-by-24 view box. Simple Icons is distributed under CC0-1.0; the depicted logo remains a trademark of Anthropic.

The `openai.svg` file is extracted without altering its path geometry from the official [OpenAI Blossom asset](https://images.ctfassets.net/kftzwdyauwt9/3hUGLn3ypllZ0oa01qOYVq/28e8188e6f11b84c3e876569d492734f/Blossom_Light.svg) and normalized to the same 24-by-24 view box as the other provider icons. Use of the logo is subject to the [OpenAI Design Guidelines](https://openai.com/brand/).

The `deepseek.svg`, `minimax.svg`, `aliyun.svg`, `gemini.svg`, `mistral.svg`, `openrouter.svg`, `ollama.svg`, and `lmstudio.svg` files come from [Simple Icons 16.21.0](https://github.com/simple-icons/simple-icons/tree/16.21.0). The `moonshot.svg` file comes from [Simple Icons 16.27.0](https://github.com/simple-icons/simple-icons/blob/16.27.0/icons/moonshotai.svg). Monochrome logos are rendered with the corresponding brand colors recorded in the Simple Icons metadata. Simple Icons is distributed under CC0-1.0, but the depicted logos remain trademarks of their respective owners and should be used according to each brand's guidelines.

The `zhipu.svg` file is extracted from the 24-by-24 `pure-logo.svg` symbol bundled by the official [Zhipu AI Open Platform](https://www.bigmodel.cn/). The `siliconflow.svg` file preserves the path geometry of the single-graphic SVG in the official [SiliconFlow logo package](https://siliconflow.cn/brand) and normalizes its transparent margins to a 24-by-24 view box.

The `volcengine.svg` file comes from [theSVG](https://github.com/glincker/thesvg/blob/aa0605996b4ad4fdda98502f84021b3c3a64847d/public/icons/volcengine/default.svg), distributed under the MIT license. The depicted logo remains a trademark of Volcengine.

The `groq.svg` file uses the standalone lightning symbol from the official [Groq favicon](https://groq.com/favicon.svg), preserving its original path geometry. The square background is omitted and its brand orange (`#F43E01`) is applied to the symbol for transparent display. The depicted logo remains a trademark of Groq; see its [trademark policy](https://groq.com/trademark-policy).

The `xiaomi-mimo.png` file is the Xiaomi MiMo mark used by both the pay-as-you-go API and Token Plan presets.

The `opencode.svg` file comes from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/master/icons/opencode.svg), preserving its original path geometry in a 24-by-24 view box. Simple Icons is distributed under CC0-1.0; the depicted logo remains a trademark of OpenCode.

The `stepfun.svg` file uses the standalone mark from the official [StepFun wordmark](https://www.stepfun.com/assets/logo-B0FsyLQP.svg), preserving its original path geometry and omitting the wordmark. The depicted logo remains a trademark of StepFun.

The `commandcode.svg` file is the official Command Code logomark from [Command Code brand assets](https://raw.githubusercontent.com/CommandCodeAI/command-code/refs/heads/main/.github/commandcode/symbols/black-symbol-commandcode.svg). The depicted logo remains a trademark of Command Code.

The `open-design.svg` file is the official Open Design symbol from [open-design.ai/logo.svg](https://open-design.ai/logo.svg). The depicted logo remains a trademark of Open Design.

Kimi Code reuses `moonshot.svg` because Kimi Code is the Moonshot AI coding subscription.

Custom providers use generated initial avatars.
